# Content Types Definition

## 1. Policy Document (ID: CT-Policy)
- Department (Choice)
- Document Type (Choice)
- Expiry Date (Date)
- Confidentiality (Choice)

## 2. News Article (ID: CT-News)
- Department (Managed Metadata)
- Category (Choice)

## 3. Project Page (ID: CT-ProjectPage)
- Project Manager (User)
- Project Category (Choice)
- Status (Choice: Green, Yellow, Red)

## 4. KB Article (ID: CT-KBArticle)
- Keywords (Text)
- Category (Choice)
