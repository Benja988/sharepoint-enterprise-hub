# Metadata Model

## 1. Site Columns
- Department (Choice: HR, IT, Finance, Admin, Projects)
- Document Type (Policy, Form, SOP, Memo)
- Confidentiality (Public, Internal, Restricted)
- Expiry Date (Date)
- Author (User)

## 2. Managed Metadata (Term Store)
Corporate Taxonomy
 ├── Departments
 ├── Document Types
 ├── Business Units
 └── Countries

## 3. Enterprise Keywords
Enabled for all document libraries.

## 4. Custom Metadata Use Cases
- Filtering policies by department
- Rolling up “News” across all department sites
- Auto-expiry workflows on documents
